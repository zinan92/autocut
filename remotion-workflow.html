Remotion Host Overlay Workflow

这张图描述可复用的视频生产线：从一个 talking-head 源视频，经过转写、AI storyboard、orientation routing、Remotion render、截图 QA、handoff，得到透明 Remotion 图层风格成片。默认规则：竖屏输入产出竖屏，横屏输入产出横屏。

Deterministic：脚本规则流程
Stochastic：LLM 判断或生成
State：文件移动、manifest、产物落盘
External：ffmpeg、ffprobe、Remotion CLI、Whisper

两个核心问题

Routing

主路由是固定流程

当前不让 AI 决定下一步去哪。`render-workflow.mjs` 读取 manifest，调用 `ffprobe`，根据宽高确定 composition：竖屏走 `HostOverlayVideo`，横屏走 `HostOverlayReferenceV9`。

AI Judgment

AI 只在既定节点内判断

AI 负责转写纠错、storyboard/phase 生成、视觉 QA 评价。它不负责文件路由、不决定是否跳过 render、不决定输出横竖屏。

Prompts

AI 节点需要固定 prompt

已沉淀固定 prompt：`transcript-correction-system.md`、`storyboard-system.md`、`visual-audit-system.md`。下一步是脚本自动读取这些 prompt 调 AI。

Attention Contract

One Active Motion

同一时间只更新一个主动画

左边和右边可以同时存在，但不能同时抢注意力。一个概念正在出现时，其他区域只能作为静态上下文。

Storyboard Decision

AI 决定保留、淡出或覆盖

AI 在 storyboard 节点为每个概念标注：active primary、passive context、fade out、freeze、replace。这个判断受固定 prompt 约束。

Audio Layer

SFX 和 BGM 放在 Remotion

音效、背景音乐用 Remotion 的 <Audio> 和 <Sequence> 编排。当前不需要新 repo。

13 个 Stage

1. Open Job
State

创建或复制 manifest

  • 从 workflow/manifest.template.json 复制新 job。
  • 写入 sourceVideo、projectName、topic 和初始要求。
  • 这是状态入口，不调用 AI。
input: user source path
output: workflow/manifest.json
2. Probe Source
Deterministic + External

读取视频元数据

  • 脚本调用 ffprobe。
  • 得到 width、height、fps、duration、size。
  • 输出 vertical 或 landscape。
script: detect-orientation.mjs
output: orientation JSON
3. Route Composition
Deterministic

固定路由，不问 AI

  • 竖屏：HostOverlayVideo。
  • 横屏：HostOverlayReferenceV9。
  • 除非 manifest 显式 override，否则不改变源视频方向。
input: orientation
output: composition id
4. Prepare Asset
State

复制源视频到 Remotion public

  • 将 sourceVideo 复制为 public/host.mp4。
  • Remotion components 统一从这个路径读取。
from: source video
to: public/host.mp4
5. Transcribe
External + AI

语音转文字

  • Whisper 或类似工具生成 txt/srt/vtt/json。
  • 这是 ML 模型输出，结果需要后续纠错。
input: audio/video
output: transcript/source.*
6. Correct Transcript
Stochastic

AI 纠错但不改意思

  • 使用固定 prompt：workflow/prompts/transcript-correction-system.md。
  • 纠正 ASR 错词、同音词、专有词。
  • 输出 correction notes。
input: ASR text
output: corrected transcript
7. Build Storyboard
Stochastic

AI 生成 phases 和字幕结构

  • 使用固定 prompt：workflow/prompts/storyboard-system.md。
  • 拆 chapters、phases、captions、skillBoard。
  • 为每个视觉元素标注 active primary / passive context / fade / freeze / replace。
  • 保证同一时间只让一个主动画更新。
  • 写入 src/storyboard.json，作为 Remotion 的内容源。
  • 5-10 分钟视频默认拆成 60-120 秒 segment，每 20 秒左右一个 visual beat。
output: storyboard md + src/storyboard.json
8. Compose Remotion
Deterministic + State

模板渲染图层

  • React/CSS 决定视觉系统、动画、SFX、字幕布局。
  • Remotion 时间轴执行 attention choreography：新动画进场，旧动画冻结、变暗或退场。
  • 当前 phases/captions/chapters/duration 从 src/storyboard.json 读取。
input: host.mp4 + composition code
state: src/Composition.tsx
9. Audio Layer
Deterministic + External

放置 SFX 和背景音乐

  • SFX 统一放在 public/sfx/。
  • 背景音乐统一放在 public/music/。
  • Remotion 用 <Audio> 和 <Sequence> 按时间点混音。
  • BGM 默认低音量，并应避开讲话主频。
assets: public/sfx
future: public/music
10. Render
Deterministic + External

执行 Remotion CLI

  • 先 npm run lint。
  • 再 npx remotion render。
  • 输出 raw mp4 到 renders。
script: render-workflow.mjs
output: *-raw.mp4
11. Delivery Encode
Deterministic + External

生成平台安全版本

  • ffmpeg 固定输出尺寸、SAR、DAR、像素格式和音频格式。
  • 竖屏固定 720x1280，横屏固定 1920x1080。
  • Telegram 上传时显式传 width、height、duration。
output: delivery-safe *.mp4
12. QA Frames
Deterministic + External

抽 still 和 contact sheet

  • ffmpeg 按 manifest 的 frame list 抽图。
  • 生成 2x2 contact sheet 供视觉审查。
output: workflow-frames/*contact-sheet.png
13. Visual Audit
Stochastic + Deterministic

AI 审查固定检查项

  • 使用固定 prompt：workflow/prompts/visual-audit-system.md。
  • 检查遮挡、字幕安全区、横竖屏是否正确、是否接近参考风格。
  • 检查是否同时有多个主动画在更新，导致 attention 被拉扯。
  • 是否继续迭代由人工或明确阈值决定，不让 AI 自由跳流程。
input: contact sheet
output: visual QA notes
14. Handoff
State

交付和复用记录

  • 写入 production handoff 和 match audit。
  • 记录最终 render、contact sheet、source metadata、阻塞点。
output: deliverables/*handoff.md
*match-audit.md

固定 Prompt 边界

AI 节点固定 system prompt允许 AI 做什么不允许 AI 做什么
Transcript Correctionworkflow/prompts/transcript-correction-system.md纠正 ASR 错误、列 correction notes改写观点、加入新内容
Storyboard Builderworkflow/prompts/storyboard-system.md拆 phases、字幕、视觉隐喻、skill board改变横竖屏路由、虚构 speaker 没说的内容
Visual Auditworkflow/prompts/visual-audit-system.md检查遮挡、字幕、安全区、注意力过载、参考风格差距自由决定跳到其他流程、忽略 manifest 规则

当前自动化程度

已经自动化：横竖屏检测、composition 路由、复制素材、storyboard 校验、JSON 驱动 Remotion、lint、render、delivery-safe encode、contact sheet、ffprobe、打开成片。

半自动：转写纠错、storyboard、attention choreography、视觉 QA 已经有固定 prompt，但还没有接入一个统一的 AI runner。

音频决策：SFX 和 BGM 先放在 Remotion 内部，用 <Audio> 时间轴处理；不新建 repo。

还未自动化：AI runner 还没有自动把 transcript 生成 src/storyboard.json；5-10 分钟视频的 per-segment QA contact sheet 还需要脚本化。

cd remotion-host-overlay-demo
npm run workflow:detect
